Chapitre 3 — Gérer les Commandes
Suivre, filtrer, affecter et superviser toutes les commandes

Dans le menu gauche, "Commandes" contient 4 sous-pages. Cliquez sur la flèche pour les voir.

3.1 — Sous-page "Confirmation"

C'est la page principale des agents. En tant que superviseur, vous la consultez pour surveiller l'avancement du traitement des commandes.

👁️ Ce que vous voyez sur cette page
  • Toutes les commandes en cours de confirmation, classées du plus récent au plus ancien
  • Des onglets de statut en haut pour filtrer : Nouveau · PDR · Reporté · Confirmé · Injoignable · Annulé
  • Pour chaque commande : code, client, produits, montant, agent affecté, statut, date
  • Un filtre par agent pour voir uniquement les commandes d'un agent précis

Comment utiliser les filtres :

1
Filtrer par statut Cliquez sur un onglet (ex: "Confirmé") pour n'afficher que ces commandes.
2
Filtrer par agent Utilisez la liste déroulante "Tous les agents" pour sélectionner un agent précis et voir uniquement ses commandes.
3
Ouvrir une commande Cliquez sur le code de la commande (ex: CMD-230526-XXXXX) pour ouvrir la fiche détaillée.

3.2 — Sous-page "En attente validation" ⭐ LA PLUS IMPORTANTE

Cette page liste les commandes confirmées par un agent mais pas encore envoyées en livraison. C'est votre principale action quotidienne.

✅ Comment affecter une commande confirmée à un livreur
1
Aller dans Commandes → En attente validation Vous voyez la liste des commandes confirmées en attente.
2
Cliquer sur le code d'une commande La fiche détaillée s'ouvre.
3
Dans la colonne droite, repérer le bloc vert "Affecter à un livreur" Ce bloc n'apparaît que pour les commandes au statut CONFIRMÉ.
4
Sélectionner le livreur dans la liste déroulante Tous les livreurs actifs apparaissent. Choisissez celui qui couvre la zone de livraison.
5
Ajouter des instructions si nécessaire (optionnel) Ex : "Livrer avant 12h", "Appeler avant de partir", "Demander M. Konaté".
6
Cliquer sur "Envoyer en livraison" La commande passe automatiquement au statut EN_LIVRAISON et apparaît chez le livreur.

3.3 — Sous-page "Commandes" (liste complète)

Vue exhaustive de toutes les commandes avec filtres avancés. Utilisez-la pour les audits et recherches.

  • Filtrez par période (aujourd'hui, semaine, mois...)
  • Filtrez par statut via les onglets en haut
  • Filtrez par agent via la liste déroulante

3.4 — Sous-page "Annulé-terminé"

Archive des commandes annulées et retournées. Utile pour analyser les raisons d'échec et calculer le taux de retour.

Chapitre 4 — La fiche détaillée d'une commande
Toutes les actions possibles depuis la fiche commande

Cliquez sur n'importe quelle commande pour ouvrir sa fiche. Elle est divisée en deux colonnes :

  • Colonne gauche (grande) : Infos client, produits, script confirmation, historique appels
  • Colonne droite (petite) : Actions, informations, livraison

4.1 — Réaffecter une commande à un autre agent

Si un agent est absent, a fait une erreur, ou si vous souhaitez rééquilibrer la charge de travail.

🔄 Changer l'agent affecté à une commande
1
Ouvrir la fiche de la commande Cliquez sur le code commande depuis n'importe quelle liste.
2
Colonne droite → bloc "Informations" → section "Changer l'agent" Un menu déroulant affiche tous les agents actifs.
3
Sélectionner le nouvel agent Ou choisir "— Désaffecter —" pour retirer l'agent sans en affecter un autre.
4
Cliquer sur "Valider" La commande est immédiatement visible dans la liste du nouvel agent.
⚠️ Cette action n'est pas disponible pour les commandes déjà en livraison, livrées, retournées ou annulées.

4.2 — Modifier les frais de livraison

Par défaut, la livraison est gratuite pour le client (prise en charge par HelpMeProcess). Pour les clients en province ou zones éloignées, vous pouvez la rendre payante.

💰 Basculer entre "Livraison gratuite" et "Payante par le client"
1
Ouvrir la fiche de la commande
2
Colonne droite → bloc "Frais de livraison" Vous voyez le statut actuel : ✅ Gratuit ou 💰 Payant
3
Cliquer sur "Mettre payant" Les frais de livraison de la ville du client s'appliquent. Le total de la commande se recalcule automatiquement.
4
Pour annuler, cliquer sur "Remettre gratuit" Les frais reviennent à 0 et le total est corrigé.

4.3 — Consulter l'historique des appels

Dans la colonne gauche, le bloc "Historique des appels" montre tous les appels passés par les agents avec : date, heure, résultat et notes. Utile pour auditer le travail d'un agent.

4.4 — Ajouter une note ou un appel

📝 Enregistrer un appel ou une note depuis la fiche
1
Dans le bloc "Historique des appels", remplir le formulaire Sélectionner le résultat de l'appel dans la liste déroulante.
2
Ajouter une note (optionnel) Ex : "Client confirme mais veut la livraison samedi matin uniquement".
3
Cliquer sur "Enregistrer l'appel" La note est sauvegardée avec votre nom et l'heure automatiquement.

4.5 — Voir la raison d'un retour non livré

Quand une commande est au statut RETOURNÉ, un bloc rouge apparaît dans la colonne droite avec :

  • La raison du retour saisie par le livreur
  • La date et heure du retour

Si le livreur n'a pas saisi de raison, le message "Aucune raison saisie" s'affiche — contactez le livreur directement.

5.2 — Marquer une commande comme "Livrée"

✅ Valider une livraison réussie
1
Aller sur la page Livraisons
2
Trouver la commande concernée Vous pouvez filtrer par livreur ou par statut.
3
Cliquer sur le bouton vert "Livré ✅"
4
Confirmer le montant collecté Le montant est pré-rempli avec le total de la commande. Modifiez-le si le livreur a collecté un montant différent.
5
Valider La commande passe en statut LIVRÉ. La facture COD est générée automatiquement. Le stock est définitivement sorti.

5.3 — Marquer une commande comme "Retour non livré"

❌ Enregistrer un retour non livré
1
Trouver la commande sur la page Livraisons
2
Cliquer sur le bouton rouge "Retour ❌"
3
Saisir la raison du retour Ex : "Client absent", "Adresse introuvable", "Client a refusé à la porte", "Numéro incorrect".
4
Confirmer La commande passe en RETOURNÉ. Le stock est automatiquement restitué. La raison est visible dans la fiche commande.

5.4 — Modifier un montant collecté après livraison

Si le montant réel collecté par le livreur est différent du montant prévu (ex : remise accordée, article manquant) :

✏️ Corriger le montant collecté
1
Sur la page Livraisons, trouver la livraison livrée
2
Cliquer sur l'icône de modification du montant Un champ s'affiche pour entrer le montant réel.
3
Entrer le montant réel + la raison Ex : "Remise accordée car produit légèrement endommagé". Cette modification est notifiée à l'administrateur.
4
Enregistrer La modification est tracée avec votre nom, la date et la raison.

Chapitre 6 — Gérer l'Équipe
Créer, modifier et gérer les agents et livreurs

La page Équipe liste tous les membres actifs. Vous pouvez créer, modifier ou désactiver des agents et livreurs.

6.1 — Créer un nouvel agent de confirmation

➕ Ajouter un nouvel agent
1
Aller dans le menu Équipe
2
Cliquer sur le bouton "Ajouter un membre" (en haut à droite)
3
Remplir le formulaire Prénom · Nom · Email (sera son identifiant) · Téléphone · Rôle : choisir AGENT
4
Définir un mot de passe temporaire Ex : prenom2026. Communiquez-le à l'agent en privé par téléphone ou WhatsApp.
5
Cliquer sur "Créer" L'agent peut maintenant se connecter et voir les commandes qui lui seront affectées.

6.2 — Créer un nouveau livreur

Même processus que pour un agent, mais sélectionner le rôle LIVREUR. Le livreur n'aura accès qu'à ses propres livraisons.

6.3 — Les différents rôles

RôleAccèsQui peut créer ce rôle
ADMINAccès complet à toutAdmin uniquement
MANAGERSupervision — tous modules sauf paramètres systèmeAdmin uniquement
AGENTConfirmation des commandes + ses propres commandesAdmin ou Superviseur
LIVREURSes livraisons assignées uniquementAdmin ou Superviseur

6.4 — Désactiver un membre

Si un agent quitte l'équipe ou est en congé, ouvrez sa fiche dans Équipe → cliquez sur "Désactiver". Il ne pourra plus se connecter. Ses commandes restent dans l'historique.

⚠️ Ne supprimez jamais un membre. Désactivez-le uniquement. Supprimer effacerait tout son historique de travail.

6.5 — Voir la performance d'un agent

Depuis la page Équipe, cliquez sur le nom d'un agent pour voir sa fiche de performance : nombre d'appels, taux de confirmation, commandes confirmées livrées et prime calculée.

Chapitre 8 — Factures & Dépenses
Gérer la facturation COD, marchands et les dépenses

8.1 — Factures COD (clients)

Une facture COD est générée automatiquement à chaque livraison réussie. Elle représente le montant collecté auprès du client.

  • Pour consulter : aller dans Factures → Factures COD
  • Cliquer sur une facture pour la voir en détail
  • Bouton d'impression disponible sur chaque facture

8.2 — Factures marchands

C'est le relevé périodique envoyé aux boutiques partenaires. Il calcule ce que HelpMeProcess doit reverser au marchand après déduction de la commission.

Formule : Total produits livrés − Commission HMP = Net à reverser au marchand

🏪 Générer une facture marchand
1
Aller dans Factures → Factures marchands
2
Cliquer sur "Générer une facture"
3
Choisir la boutique concernée
4
Sélectionner la période (début → fin) Généralement du 1er au dernier jour du mois écoulé.
5
Vérifier le récapitulatif Nombre de commandes livrées, total brut, commission, net marchand.
6
Cliquer sur "Générer" puis "Imprimer" Sur Mac : Cmd+P → "Enregistrer en PDF". Envoyez le PDF au marchand par WhatsApp ou email.

8.3 — Dépenses

Enregistrez toutes les dépenses opérationnelles de l'entreprise.

💸 Saisir une dépense
1
Aller dans Factures → Dépenses
2
Cliquer sur "Nouvelle dépense"
3
Remplir : catégorie, description, montant, date, bénéficiaire Catégories : SALAIRE · LOYER · TRANSPORT · MARKETING · AUTRE
4
Enregistrer

Chapitre 11 — Résolution des problèmes courants
Questions fréquentes et solutions immédiates
❓ Un agent ne voit pas une commande qui lui a été affectée

Cause probable : La commande est peut-être sur un autre onglet de statut (PDR, Reporté...).
Solution : Demandez à l'agent de cliquer sur l'onglet "PDR" ou "Reporté" dans sa page Confirmation. Ou vérifiez vous-même depuis votre vue superviseur.

❓ Je veux changer l'agent d'une commande déjà confirmée

Possible si la commande n'est pas encore en livraison.
Solution : Ouvrir la fiche commande → colonne droite → "Changer l'agent" → sélectionner le nouvel agent → Valider.

❓ Le livreur dit qu'il n'a pas reçu la livraison dans son appli

Vérifier : La commande est bien au statut EN_LIVRAISON ? Le livreur est le bon ?
Solution : Demandez-lui d'actualiser sa page (F5). Si toujours absent, vérifiez que vous avez bien sélectionné son nom lors de l'affectation.

❓ Une commande est bloquée depuis plusieurs jours sans avancement

Cause : Agent n'a pas eu le temps, oubli, ou client injoignable.
Solution : Ouvrir la commande → voir l'historique des appels → si aucun appel récent, rappeler l'agent. Vous pouvez réaffecter la commande à un autre agent.

❓ Le stock d'un produit affiche 0 mais on a du stock physique

Cause : Décalage entre stock physique et stock système (retours non enregistrés, réception non saisie).
Solution : Produits & Stock → cliquer sur le produit → "Ajuster le stock" → entrer la quantité réelle avec la raison "Inventaire physique".

❓ Je n'arrive pas à me connecter (page blanche ou erreur)
  1. Vider le cache du navigateur : Cmd+Shift+R (Mac) ou Ctrl+Shift+R (Windows)
  2. Essayer dans un onglet navigation privée (Cmd+Shift+N)
  3. Essayer avec Google Chrome si vous êtes sur un autre navigateur
  4. Contacter l'admin si le problème persiste
